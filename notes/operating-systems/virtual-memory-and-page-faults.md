# 虚拟内存、按需分配与缺页异常

[返回操作系统基础目录](README.md)

## 虚拟地址、物理内存与页表

虚拟地址是程序访问内存时使用的地址。物理内存是实际保存数据的 RAM，物理地址用于定位物理内存中的位置。操作系统维护每个进程的虚拟地址区域和访问权限，CPU 按地址映射把虚拟地址转换为物理地址，再完成访问。

页是内存管理使用的固定大小的块，大小由平台决定。虚拟页属于进程的虚拟地址空间；物理页是物理内存中的块。页表记录虚拟页到物理页的映射，以及该映射的访问权限和状态。

## 申请成功与按需分配

程序成功申请一段可读写的新虚拟内存区域时，操作系统通常只登记这段区域，还没有分配同样大小的物理内存。按需分配指先登记允许访问的虚拟区域，等实际访问时再准备物理页。登记区域和维护管理信息本身也会占用少量内存。

例如，进程申请 100 MB 新虚拟内存后还没有访问，物理内存占用通常不会增加 100 MB。一次写入通常只准备被写到的内存页，整个区域不会立即分配。具体分配行为取决于申请方式和系统策略。

## 首次写入与缺页异常

缺页异常是一类异常：CPU 发现当前内存访问无法通过现有映射完成，就把控制权交给操作系统处理。缺页异常常常是正常内存管理的一部分，程序没有出错，操作系统也可能无需读取磁盘。

以新申请、不以文件为数据来源的内存为例。假设程序写入的虚拟地址合法，区域允许写入，但对应的物理页尚未分配。这次写入按以下顺序处理：

1. CPU 尝试把程序使用的虚拟地址转换成物理地址。
2. CPU 发现没有可用的映射，触发缺页异常，并暂时停止这次访问。
3. 操作系统检查虚拟地址是否属于进程的有效区域，以及该区域是否允许当前写入。
4. 访问合法时，操作系统准备物理页并更新页表。这类新内存的物理页通常先被清零，程序首次读到的内容是 0。
5. 异常处理成功后，程序重新执行触发异常的访问，完成写入。

虚拟地址合法和物理页已经存在是两个独立的条件。操作系统可以先允许访问某个虚拟区域，等访问发生时再建立物理映射。物理页准备好、异常处理成功后，程序才能继续执行。

## 缺页与非法内存访问的区别

虚拟地址属于有效区域且允许当前操作时，操作系统准备内存、更新映射，就能补上缺少的物理页。虚拟地址不属于有效区域，或者程序向只读区域写入时，访问本身是非法的，分配物理页也无法让访问合法。

非法访问产生内存访问错误；错误没有被处理时，进程通常会终止。这里的合法性只按虚拟内存区域和访问权限判断。数组越界、对象误用等语言层面的错误，只要访问落在合法区域内，硬件就发现不了。
