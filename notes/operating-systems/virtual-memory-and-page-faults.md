# 虚拟内存、按需分配与缺页异常

[返回操作系统基础目录](README.md)

## 虚拟地址、物理内存与页表

虚拟地址是程序访问内存时使用的地址。物理内存是实际保存数据的 RAM，物理地址用于定位物理内存中的位置。操作系统维护进程的虚拟地址区域及访问权限，CPU 按地址映射完成访问。

页是内存管理使用的一定大小的块，具体大小取决于平台。虚拟页属于进程的虚拟地址空间；物理页是物理内存中的块。页表记录虚拟页到物理页的映射，以及该映射的访问权限和状态。

## 申请成功与按需分配

申请一段允许读写的新虚拟内存区域成功，不代表操作系统已经为整个区域提供了同样大小的物理内存。按需分配表示先登记允许访问的虚拟区域，再在实际需要时准备物理页。登记区域及维护管理信息本身也可能产生内存开销。

例如，申请 100 MB 新虚拟内存后尚未访问，不能据此断言进程已经额外占用 100 MB 物理内存。一次写入通常只需要准备涉及的内存页，不要求立即分配整个区域。具体分配行为仍取决于申请方式和系统策略。

## 首次写入与缺页异常

缺页异常是 CPU 发现当前内存访问无法通过现有映射完成时，把控制权交给操作系统处理的一类异常。缺页异常可以是正常内存管理的一部分，不必然表示程序错误，也不必然需要读取磁盘。

以新申请、没有文件作为数据来源的内存为例，假设程序写入的虚拟地址合法、区域允许写入，但对应物理页尚未分配。访问按以下顺序处理。

1. CPU 尝试把程序使用的虚拟地址转换成物理地址。
2. CPU 发现没有可用的映射，触发缺页异常，并暂时停止这次访问。
3. 操作系统检查虚拟地址是否属于进程的有效区域，以及该区域是否允许当前写入。
4. 访问合法时，操作系统准备物理页，并更新页表。对这类新内存，程序首次获得的内容通常经过清零处理。
5. 异常处理成功后，程序重新执行触发异常的访问，完成写入。

虚拟地址合法与物理页已经存在是两个不同条件。操作系统可以先允许某个虚拟区域被访问，再在访问发生时建立所需的物理映射。上述继续执行以物理页准备和异常处理成功为前提。

## 缺页与非法内存访问的区别

如果虚拟地址属于有效区域且允许当前操作，缺少物理页可以通过准备内存和更新映射解决。如果虚拟地址不属于有效区域，或者程序向只读区域写入，操作系统不能仅靠分配物理页就把访问变成合法。

非法访问会产生内存访问错误；错误未被适当处理时，进程通常终止。这里的合法性是虚拟内存区域和访问权限层面的判断，不代表硬件一定能发现语言层面的每一种数组越界或对象使用错误。
